## UnityRoom公開チェックリスト

### 1) タグ設定（見つけてもらうための導線）
- **コアジャンル**: `アクション`, `2D`, `WebGL`
- **プレイ感**: `短時間`, `スコアアタック`, `カジュアル`
- **入力/難易度**: `マウス操作`, `初心者歓迎`（または `高難易度`）
- **差別化タグ**: `物理`, `反射神経`, `リトライ性`
- まずは **5〜8個程度** で始め、アクセス傾向を見て入れ替える

### 2) タイトル・説明文（クリック率と離脱率に直結）
- タイトルは **「動詞 + 目的 + 制約」** の形にすると意図が伝わりやすい
- 1行目で「何をすると楽しいゲームか」を明言
- 2〜4行目で「勝利条件」「1プレイ時間」「操作デバイス」を提示
- 長文よりも、箇条書きと改行を優先

#### 説明文テンプレ（短文）
```text
マウスだけで遊べる2Dスコアアタック！
限られた投げ数でターゲットを連続突破し、ハイスコアを狙おう。

- 1プレイ: 約1〜3分
- 操作: マウスのみ
- 目標: ノーミス + 連続クリア
```

### 3) 遊び方の工夫（初見30秒の体験を最適化）
- **開始直後に1目標だけ表示**（例:「まずは1000点を目指そう」）
- **最初の成功体験を10秒以内** に置く（序盤難易度を抑える）
- **失敗理由の可視化**（時間切れ/ミス回数/当たり判定など）
- リトライ導線は「結果画面 → ワンクリック再挑戦」を最短化

### 4) 画面内UI（迷わせない）
- 常時表示: `現在スコア`, `残り投げ数`, `目標値`
- 必要時のみ: `コンボ`, `ボーナス条件`, `危険アラート`
- 色は「成功=暖色」「失敗=寒色」「中立=白/グレー」で統一
- フォントサイズはPC前提で小さすぎない値を採用

### 5) 難易度とスコア設計
- 初回プレイは **70%程度で最低目標到達** できるバランスを目安
- 上級者向けに「ノーミス/高速クリア」の加点条件を用意
- ランダム要素は「運だけで決まらない」範囲に制御
- 自己ベスト更新時は演出を強く（SE・UIアニメ）

### 6) UnityRoomページ運用
- サムネイルは **一目でゲーム内容が分かる画** を使う
- 更新時は「何が改善されたか」を更新ログに短く記載
- コメントへの返信で、次回改善予定を1つ示す
- 公開初週はタグ・説明文・サムネをA/B的に見直す
